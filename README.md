中文运维交接版，更新日期：2026-10-26。个人仓库为 `FocusonXMH/shoe-prompt-workbench`，已按所有者要求公开，保存运行源码、数据库结构及中文交接说明；不更新公司仓库。GitHub 提交不会自动部署到服务器，也不包含真实运行数据。

## 项目作用

将测试过的鞋类图片、视频提示词整理为可配置模板。运营填写字段后，由网页本身确定性替换并输出可复制文本，不依赖 AI 在线识别，也不消耗模型 API。管理员可维护卖点、模板、字段、历史版本、公告、教学说明、人员及反馈。

模板中的 `【…】` 由网页扫描，管理员确认字段规则；可以保留原文、替换内容、保留前缀或按选填规则删除。字段配置同时控制前台控件、校验和输出，并非只有视觉配置。不要将参考示例中的所有括号未经确认都改为填空。

## 密码与权限特别提醒

共享账号新增、修改、停用、重置和删除会影响 CPO；人员分类属于工作台元数据，不能与身份权限角色混淆。身份系统以不可逆哈希验证密码；按负责人要求，工作台另外提供仅管理员可用的加密凭据保管与查看接口，不向普通用户开放。凭据与当前身份哈希不一致时不显示旧密码。恢复时需单独保管 `credential.key`，不要提交到源码或公开备份。

**完整源码不等于完整生产数据备份。** 本仓库不包含员工密码、腾讯云密钥、数据库密码、登录令牌、真实反馈或上传图片。取得代码权限也不自动取得服务器、数据库、CPO 或工作台管理权限。
