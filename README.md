# 鞋类提示词工作台

中文运维交接版，整理日期：2026-10-24。主仓库应为个人私有仓库；公司公开仓库暂不上传。源码归档不触发部署，不表示所有交互已完成验收。

## 项目作用

将测试过的鞋类图片、视频提示词整理为可配置模板。运营填写字段后，由网页本身确定性替换并输出可复制文本，不依赖 AI 在线识别，也不消耗模型 API。管理员可维护卖点、模板、字段、历史版本、公告、教学说明、人员及反馈。

模板中的 `【…】` 由网页扫描，管理员确认字段规则；可以保留原文、替换内容、保留前缀或按选填规则删除。字段配置同时控制前台控件、校验和输出，并非只有视觉配置。不要将参考示例中的所有括号未经确认都改为填空。

## 当前真实部署

访问入口：`https://193.112.27.91:80/shoe/`；工作台 API 前缀：`/shoe-api/`。地址使用历史端口配置，勿自行改成 HTTP。Python 后台只监听 `127.0.0.1:18808`，服务名 `shoe-workbench`。

服务器根目录：`/home/ubuntu/shoe-workbench-staging/`。`staging` 是历史名称，不代表模拟数据。数据库 `shoe_workbench_staging` / schema `shoe_workbench` 保存真实工作台数据；共享身份库位于 `amazon_ads.iam`。工作台业务数据不写入 CPO 业务表。

## 本地检查

Python 运行基线为 3.12。安装 `backend/requirements.txt` 后：

```sh
python tests/run_unit_tests.py
```

真实登录依赖现有 CPO 身份服务，单独打开 HTML 并不等于启用了数据库、共享登录与上传。不要将线上配置复制到仓库。

## 密码与权限特别提醒

共享账号新增、修改、停用、重置和删除会影响 CPO；人员分类属于工作台元数据，不能与身份权限角色混淆。密码以不可逆哈希保存，不提供查询原密码接口。忘记密码走受控重置。

**完整源码不等于完整生产数据备份。** 本仓库不包含员工密码、腾讯云密钥、数据库密码、登录令牌、真实反馈或上传图片。取得代码权限也不自动取得服务器、数据库、CPO 或工作台管理权限。

## 更新规则

内容更新走管理员发布版本；程序更新走代码审查、备份、部署、验证。GitHub 提交不会自动更新服务器。本次归档不增加 GitHub Actions 自动部署，不修改 CPO 的代码或发布流程。线上模板和用户历史以数据库为准，禁止在常规更新中重新导入 seed 或重建数据库。
