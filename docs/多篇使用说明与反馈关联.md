# 多篇使用说明与反馈关联

更新日期：2026-10-26。

## 使用说明

模板库右上角“使用说明”打开按标题排列的目录，每篇显示内容摘要及是否已查看。管理员可新增、编辑和设置草稿／发布／撤回；正文和教学图片可以分别使用，也可以组合。原 settings.help 的正文和图片迁移为“工作台使用入门”，不覆盖原内容。

首次进入且没有查看说明记录的账号显示引导目录；实际打开一篇说明或点击“我已了解”后，按稳定用户编号持久记录。切换设备仍沿用该记录。只关闭而未阅读／确认时，下次登录仍可能提示。没有已发布说明时不弹空窗口。

新增或更新已发布说明会生成／更新关联群体公告，包含标题、正文摘要和“查看使用说明”入口，不重置首次引导记录。草稿不向普通用户显示，也不发公告；撤回说明会撤回对应提醒。用户从说明中心实际打开文章时，对应公告同步记为已查看。当前不包含旧文章的逐字修改对比。

新表 help_articles 存图文及状态；help_reads 存按人按篇的阅读时间；help_onboarding 存首次引导确认。announcements.help_article_id 关联说明。教学图片仍在独立工作台 uploads 和 attachments 中，按文章发布状态校验访问。旧 /help 与 /admin/help 接口保留给旧客户端；新界面通过 /help/articles 与 /admin/help/articles/{id} 工作，维护时应使用新接口。

## 反馈提交时引用

涉及位置改为可编辑的文字说明，不再列举一长串卖点作为固定选项。用户可描述具体页面、操作或新需求，也可以留空。

提交区可选择当前已发布模板，再选择一个未删除的版本。直接从模板、卖点或历史版本发起反馈时自动带入相应上下文；用户仍可更换模板、版本或取消引用，并修改位置描述。输入说明不会被异步刷新目录覆盖。

反馈根记录存 template_reference（模板 ID、标题、版本及版本名），不复制整份正文。列表提供直接打开对应版本的入口；回复也保留原有引用能力。历史位置文字保留用于追溯，模板或版本被删除后不会自动跳到不同版本。

在既有 016 及前置结构完成后执行 migrations/017_help_center.sql，再部署 backend/help_center.py、app.py、collaboration.py、前端和 cloud-api.js。不改 CPO 业务表。数据库结构脚本不在普通启动时自动重跑。

浏览器验证首次引导、保留原说明内容、已查看后重新载入不弹窗、管理员新增表单及首次提交引用；临时反馈已移除，没有保存临时说明或向员工发布演示文章。
