# 数据存放与 CPO 关联

## 服务器分配

同一台腾讯云服务器承载 CPO 与工作台。入口由 Nginx 转发；工作台服务独立运行在 18808 内部端口。两个系统不是分别购买的服务器，也不是将工作台数据混入广告业务表。

```text
浏览器 /shoe/、/shoe-api/
  └─ shoe-workbench（127.0.0.1:18808）
      ├─ 独立业务库 shoe_workbench_staging.shoe_workbench
      ├─ uploads 图片文件
      ├─ CPO 身份接口（127.0.0.1:8000/api/auth/*）
      └─ 受限共享身份连接 amazon_ads.iam
```

## 工作台数据表

| 表 | 内容与用途 |
| --- | --- |
| selling_points | 卖点名称、排序、归档状态 |
| templates | 模板资料、草稿、发布版本指针 |
| template_versions | 发布快照、字段配置与提示词正文 |
| feedback | 反馈内容、提交人、状态、关联模板或公告、软删除标记 |
| feedback_messages | 对话回复、引用关系 |
| attachments | 图片编号、文件键、类型、大小及关联 |
| announcements | 群体公告、个人通知、发布与撤回信息 |
| announcement_reads | 按人记录已读、实际打开和直接标已读 |
| settings | 使用说明、反馈类别等配置 |
| user_preferences | 收藏、个人排序与使用偏好等 JSON 配置 |
| events | 模板打开、复制、版本选用、收藏变动等事件 |
| field_usage | 短字段值的按人／模板／版本词频 |
| user_profiles | 人员分类、身份资料快照、近期在线时间 |
| account_audit | 工作台发起的账号操作记录 |
| password_requests | 密码重置申请 |
| local_accounts / local_sessions | 保留的独立身份机制；常规新增入口不使用它 |
| login_attempts | 登录尝试控制 |

图片实体存放在根目录的 `uploads/`，数据库保存关联而非将整张图片塞入正文。反馈、公告、教学图片共用上传根目录，按数据库关系区分；当前没有独立 COS 桶，也不能声称已经为每张图生成缩略图。原图按需读取，并有登录及归属校验。

浏览器仍可能保存界面偏好、临时输入等状态；不是所有浏览器数据都自动成为云端持久数据。业务记录是否云端保存应以对应接口与数据库实际写入为准。

## 共享账号真实影响

工作台登录先由 CPO `/api/auth/login` 验证，后续 `/api/auth/me` 验证身份。账号管理使用专用受限连接操作 `iam.users`，不是只复制密码名单。

| 操作 | 影响 |
| --- | --- |
| 新增共享账号 | 写入共享身份库，CPO 可验证该账号；业务访问仍受 CPO 自身规则约束 |
| 修改账号、姓名、权限角色 | 修改共享记录，可能影响 CPO 的角色授权 |
| 停用、密码重置 | 影响两边登录；相关共享会话被撤销 |
| 删除共享账号 | 影响两边；存在外键业务依赖时拒绝，改用停用 |
| 修改人员分类 | 写工作台 user_profiles，不等于给 CPO 分配业务权限 |

内部关联以稳定 user_id 为准，不以姓名或可改的账号字符串作为唯一关联。新运营按现有代码分配未占用的 `SHOE0001` 形式编号；不得声称与 CPO 原业务编号语义完全一致。其他新角色需检查 CPO 的访问规则。

## 凭据究竟在哪里

- 员工密码哈希：共享 `iam.users.password_hash`，不是可解密的明文。
- 工作台数据库连接与共享身份连接：服务器根目录 `database.env`（受限文件），不随源码上传。
- 腾讯云 SSH 密钥：授权运维人员本地安全保管，不在仓库。
- 重置临时密码：仅受控操作返回给管理员交付本人，不写入 README。
- 钉钉文档：当前未建立自动读取或自动同步连接，不能作为运行时认证源。

仓库中的表名与配置位置是对接说明，不是授予数据库访问权限。其他系统不得通过查询明文员工密码来实现登录。
