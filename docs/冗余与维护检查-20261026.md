# 前后端冗余与维护检查

日期：2026-10-26。范围：当前工作台运行前端、20 个后台 Python 文件、72 组 HTTP 方法与路径，以及部署和恢复说明。此检查是静态结构扫描、人工依赖核对与部分线上回归结合，不等于全部操作组合、全部设备或高并发压测完成。

## 已清理并部署

- 移除“体验反馈对话／试发回复”演示卡片及其事件，保留真实反馈和回复。
- 移除旧本地用户管理实现。它原先会被后面的真实服务器实现覆盖，却仍保留本地随机密码、停用和修改信息逻辑；现在只保留真实用户管理入口。
- 移除隐藏的本地修改密码弹窗、旧修改角色弹窗及其事件，真实共享账号管理和密码重置接口保留。
- 移除早期 localStorage 业务加载器及专用存储键。当前个人设置仍通过真实服务保存，不删除已有浏览器或云端记录。
- 移除无人调用的“我的卖点顺序”上下移动弹窗、按钮事件及渲染函数；保留直接拖动排序。
- 移除不可达的智能助手占位页、弹窗和专属样式，移除旧联调身份模拟分支。
- 移除默认数据内的虚构反馈、云端待接入公告。正常使用说明中的填写示例保留。
- 删除未被运行网页引用的 api-adapter.js。真实请求继续使用 cloud-api.js。
- 公告渲染不再覆盖同名函数，不再创建随后立即删除的“查看”按钮；保留整行查看、编辑、撤回、删除和服务端已读统计。
- 维护视角只保留页面上方的退出入口，移除横幅内同一操作的重复按钮。
- 后台对话读取复用一次匿名编号映射；作者资料按本次请求缓存，避免每条回复重复查同一人的资料。缓存不跨用户或请求，不改变匿名身份和撤回内容的权限规则。
- 修正 README 旧的“无法查看密码”说明，说明实际管理员加密凭据查看机制；补齐初次部署需执行的后续 SQL 清单，明确共享身份授权须另外审查。

## 保留的内容与原因

- 数据迁移和旧身份兼容接口：旧账号、旧版本和恢复过程可能依赖，不能根据当前页面没有调用就判定为无用。
- prompt-data.js、seed.json 和素材导出脚本：属于初始素材和空库初始化链路，不在日常更新时重导入。
- 模板打开、复制、收藏、历史版本选择是不同事件，不合并成一个“使用次数”。
- 回复软删除占位、匿名编号对应历史参与顺序，均不能随意物理删除，否则会破坏后续引用和隐私展示。

## 仍需按阶段维护

1. **恢复完整性**：现有备份脚本保存工作台数据库和图片，但未包含 credential.key，也不备份共享 IAM。公司应单独保管解密密钥并为共享身份安排备份；数据库备份本身不能恢复可查看凭据。此次未将密钥复制到源码或公开目录。
2. **迁移可追踪性**：后续 SQL 目前仍在 backend 中，初次部署清单已补齐，但还没有迁移执行记录表和统一执行器。后续应新增有序迁移机制，再迁移目录；不可修改旧脚本冒充升级或直接重跑全套。
3. **前端模块拆分**：当前约 254 KB 的 index.html 仍集中包含样式、模板编辑、反馈、身份、公告和统计逻辑。后续宜分业务模块逐步迁出，并保留端到端回归，不能用一次大范围替换冒险减少文件大小。
4. **同账号并行保存**：依照已确认规则仍采用后保存覆盖；同浏览器多个标签共用登录身份。这不是本次清理引入的问题，也没有在此轮变更为独立会话或冲突合并。
5. **统计口径与规模**：本次没有新增完整压力测试，不能由小规模回归推断任意在线人数。随着用户和讨论量增长，应观察接口耗时、连接池等待和图片体积，再决定分页与容量调整。
