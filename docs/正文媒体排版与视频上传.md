# 正文媒体排版与视频上传

更新日期：2026-10-26。

## 使用规则

使用说明、公告、反馈主帖和回复支持图片与视频。支持 PNG、JPEG、MP4、WebM，单附件上限仍为 10 MB；说明、公告最多 50 个附件，反馈每次最多 6 个。视频使用原生播放控件，preload=none，不自动播放；未接入视频转码或自动压缩。

在正文光标处粘贴截图，图片插入当前位置，光标移动到下方，可接着写解释。通过“添加图片／视频”选择的文件没有正文锚点，集中放在全文末尾；两种方式可同时使用。粘贴文字只接收纯文本，不导入剪贴板 HTML。Tab 保留为空格缩进。

现有纯文字和末尾附件继续正常展示。编辑已有正文时可调整文字和插图位置；从正文移除图片不等于物理删除历史附件，未被正文引用而仍保留的附件会显示在末尾。清除已保存附件是说明／公告的独立操作。

## 数据和权限

正文仍是纯文本，图片位置以内部附件锚点保存；不在文字字段写 base64，不保存任意 HTML。文件实体继续在工作台 uploads，元数据在 attachments，数据库未增加图像正文大字段，也不改 CPO 表。

说明和公告保存时将本地临时锚点替换为已上传的附件编号。反馈先创建记录，再上传附件，由 POST /feedback/{id}/inline-media 校验归属后替换锚点。只能调整本人正文，回复只能引用属于该回复的附件；不能跨反馈引用其他人的文件。

读取时只渲染已授权、存在于本条附件集合中的锚点；失效或未上传完成的附件显示提示，不公开本地临时编号。通知摘要将锚点转为“附件”提示。撤回、删除、匿名和附件读取规则保持。

## 代码与部署

- frontend/media-editor.js：共用正文编辑、纯文本序列化、附件锚点、上传缓存及展示。
- backend/media_support.py：统一文件类型／体积校验和反馈锚点归属校验。
- help_center.py、app.py、collaboration.py：按原业务权限返回媒体类型与正文关联。

本次不新增数据库迁移，但要求现有 001—017 及相关后续 SQL 已完成。部署必须包含新前后端模块，不能只复制 index.html 或 app.py。

## 验证范围

服务器运行环境中的 12 项身份、权限和媒体校验单元测试通过；协作集成测试增加主帖／回复位置持久化、跨用户及跨反馈拒绝、说明和公告视频类型读取，原有匿名、版本引用、消息清理及账号切换回归通过。本地重跑完整测试需先安装 backend/requirements.txt；仅有基础 Python、未安装 FastAPI 时不能运行媒体测试。

浏览器实际执行：正文粘贴截图后继续输入、提交主帖、回复图文保存、刷新重新查看、粘贴图片与按钮附件同时使用、编辑已有反馈、说明图文草稿保存和重新打开。临时反馈通过正常入口移除；专门的说明草稿及其不共享附件已清理。没有向员工发布演示说明或公告。

格式校验测试使用小型文件头样本，不代表视频解码或所有编码已完成跨浏览器验收。浏览器排版验证使用专门的 PNG 图文测试素材。
